# gap_sdk_private v5.20.4

## clone
```
git clone --recursive git@github.com:LorenzoLamberti94/5.20.4.git
```

## python env

```
conda create -n gap_sdk_5.20.4 python=3.10.16
conda activate gap_sdk_5.20.4
```

To run deployment in jupyter notebooks run

```
conda activate gap_sdk_5.20.4
conda install ipykernel jupyter
python -m ipykernel install --user --name gap_sdk_5.20.4 --display-name "gap_sdk_5.20.4"
# open jupyter as follows
jupyter notebook
```
